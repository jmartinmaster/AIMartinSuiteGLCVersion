# Security Policy

## Supported Versions

All updates will be made as I have time to make them.

Only the latest version will receive security updates. The security updates will be included with any standard update. 
Development versions will have all latest features for testing, including security updates, in progress or finished, as needed.

## Reporting a Vulnerability

If there is a security issue or vulnerability you want addressed, please report it in the issue tracker. 
Use the tag Security Issue or Security Vulnerability as needed for these issues.
Misuse of these tags will not be tolerated and may result in the loss of these tags.
